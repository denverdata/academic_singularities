# Project Theoretical Foundation: Debunking Singularities

## Theoretical Premise
The "Singularity" in modern physics is identified as a mathematical artifact rather than a physical reality. This project seeks to demonstrate that all such "blow-ups" (UV catastrophes, black hole singularities, Big Bang origins) are rooted in a fundamental misinterpretation of mathematical limits and the "division by zero" fallacy.

## Key Theoretical Axioms
1. **Physical Persistence**: Every physical system has finite spatial extent and mass. The "point mass" is a useful mathematical locator but not a physical entity.
2. **Limit Definition**: A limit $L$ describes a boundary that is approached but never reached. To equate "approaching $0$" with "becoming $0$" is a logical error that invalidates the resulting physics (e.g., infinite density).
3. **Inertial Emergence of Time**: Time is not a fundamental background but an emergent property of a system's resistance to acceleration (inertia).
4. **Relativistic Scale**: All measurements are relative to the observer's own inertial scale. As scale changes, the "pace of time" changes proportionally.

## Argumentative Structure
- **Algebraic Refutation**: Show that $1/x$ never equals $0$ for any real $x$.
- **Floating Point Reality**: In both computational and physical contexts, there is no "literal zero" that would permit a division by zero error in a persistent system.
- **Observational Perspective**: Observed phenomena (like redshift) are interpreted through relative inertial time dilation rather than spatial expansion.
